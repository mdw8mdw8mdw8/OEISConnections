This page is a "connections"-like game using sequences from the OEIS (www.oeis.org).  
There are four sets of consecutive (in their sequence) numbers from four different OEIS sequences.  
Beware: In some cases a number may be part of more than one sequence, but there is only one correct sequence it is part of.
For example:  5,14,42,132 and 5,8,13,21 are sequences that both contain the number 5, but in the puzzle:

8     14   45   120

11    24   42    34

13     6   2    132

197    3   21    5

The correct sequence that includes 5 is A108 Catalan:  5,14,42,132.

Full Solution:  

   A45 Fibonacci:     8,13,21,34
   A108 Catalan:      5,14,42,132
   A142 Factorial:    2,6,24,120
   little Scrhoeder:  3,11,45,197
